# Criticality Calculator

Computes $k_\infty$ via the six-factor formula and estimates $k_{eff}$ for simple bare geometries using geometric buckling.

## Six-Factor Formula

$$
k_\infty = \eta \, \varepsilon \, p \, f
$$

## Geometric Buckling

Supported:
- Infinite slab
- Bare sphere
- Finite bare cylinder

## Educational Value

Reinforces how geometry (leakage) reduces multiplication factor from the infinite-medium value.
