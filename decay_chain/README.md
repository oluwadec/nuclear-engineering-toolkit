# Radioactive Decay Chain Calculator

Numerical solution of the Bateman equations for linear decay chains.

## Features

- Arbitrary length chains
- Numerical integration (robust for widely different half-lives)
- Activity calculation
- Clear visualization of transient and secular equilibrium regimes

## Example Use Cases

- Understanding why daughter activity can exceed parent activity
- Medical isotope generators (e.g., Mo-99 → Tc-99m simplified)
- Simplified actinide or fission product chains for lab reports
