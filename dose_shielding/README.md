# Dose Rate & Shielding Estimator

Interactive Streamlit application for approximate gamma dose rate and shielding calculations.

## Run

```bash
streamlit run app.py
```

## Features

- Point source inverse-square dose rate estimate
- Exponential attenuation with simple buildup factor
- Common shielding materials (lead, concrete, steel, water, etc.)

## Warning

This is an **educational** tool only. Real radiation protection calculations require energy-dependent cross sections, proper buildup factors, geometry corrections, and validated software.
